# Security Policy

Cats Compression opens zip files that may come from anyone, so security reports are taken seriously.

## Supported versions

Only the [latest release](https://github.com/Ushmayne/File-Compression-Utility/releases/latest) gets security fixes.

## Reporting a vulnerability

**Please don't report security problems in public issues.**

Report them privately through GitHub instead: go to the repo's [Security tab](https://github.com/Ushmayne/File-Compression-Utility/security) and click **Report a vulnerability**.

Please include:

- what the problem is and what an attacker could do with it
- steps to reproduce it, ideally with a sample zip file
- the app version you tested

You should get a reply within a week. Once the problem is fixed and a new release is out, the report can be made public, with credit to you if you'd like.

Examples of things worth reporting: a zip file that writes files outside the folder you chose, overwrites files without asking, or crashes the app in a way that could be exploited.
